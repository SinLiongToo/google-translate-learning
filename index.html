系統使用說明與操作手冊

User Manual

歡迎使用 Google 翻譯詞庫互動學習系統！本系統將您在 Google 翻譯中標記星號儲存的單字與片語，自動轉化為具備 3D 抽認卡、多國語言母語語音、智慧分類與知識圖譜的現代化學習工具。

📇 3D 翻牌抽測模式

模擬實體抽認卡（Flashcards），正面為外語原文，背面為中文釋義。點擊卡牌本體或按 Space 即可在 0.2 秒內平滑 3D 翻轉。

  • 支援 🔊 正反面獨立母語發音（英/法/中自動切換）。
  • 支援 ▶ 自動播放功能：可自由選擇「🌐 雙語模式」（外語 ➔ 自動翻牌 ➔ 中文釋義）或「🔤 英文/純外語模式」（純英文/法語沉浸聽力，不朗讀中文）。
  • 可手動標記 🔴 困難、🟡 學習中、🟢 已精熟。
  • 點擊 🎲 抽卡 可將現有篩選範圍內的卡片隨機洗牌。
📋 詞庫清單與搜尋

以結構化表格檢視所有已收錄條目，支援毫秒級全域模糊搜尋與多維條件篩選。

  • 輸入關鍵字即時比對原文、釋義或備註。
  • 可依語系（英中、法英、法中）、分類主題與掌握狀態篩選。
  • 點擊任一項目右側的 👁️ 按鈕可滑出側邊詳細資訊抽屜。
✍️ 隨機自我測驗 (Quiz)

隨機抽取 10 題進行四選一測驗，包含「外語選中文」與「中文選外語」雙向題型。

  • 即時反饋答對/答錯，並記錄錯題。
  • 完成 10 題後即時結算分數並列出租錯題清單方便針對性複習。
🕸️ 知識網絡圖譜 (Graph)

基於原生 Canvas 物理引擎的力導向網絡圖，直觀展現各單字與分類主題的聚類關係。

  • 滑鼠滾輪縮放、拖曳畫布自由平移探索。
  • 點擊任一單字節點直接開啟側邊欄檢視詳細釋義與發音。

🎭 欄位遮蓋情境 (主動回想練習)

透過頂部導航列下方的「欄位遮蓋開關」，可一鍵套用不同自測情境：

遮背面（測理解）

隱藏中文翻譯，強迫自己看到英文/法文時在大腦中提取中文意思。

遮正面（默背原文）

隱藏外語原文，看中文練習拼字或在心裡默唸正確外語單字。

🌐 語系配對與法語對翻功能說明

收錄 105 筆法語

Google 翻譯匯出檔中若混雜了法語與英語，系統已自動為您精準拆分與辨識，絕不互相混淆：

🇫🇷 法語原生發音

點擊法文單字時，自動呼叫瀏覽器原生 fr-FR 法語語音引擎朗讀，保留道地法式腔調。

🇬🇧 英語標準發音

英語單字調用 en-US 發音，繁體中文調用 zh-TW 發音。

🎯 專屬下拉篩選

可一鍵切換「🇫🇷 所有法語對翻」、「🇫🇷⇄🇬🇧 法英對翻」或「🇬🇧⇄🇹🇼 英中對翻」。

📱 如何安裝到手機 / 平板主畫面（宛如原生 App）

本系統已具備極速響應式設計，您可以直接將其加到行動裝置桌面，隨點即學：

🍎 iPhone / iPad (Safari)
  1. 以 Safari 開啟本線上網址。
  2. 點選底部分享按鈕（方形帶向上箭頭 📤）。
  3. 滑動選單並點擊 「加入主畫面 (Add to Home Screen)」。
🤖 Android 手機 (Chrome / Edge)
  1. 以 Chrome 開啟本線上網址。
  2. 點選右上角三點選單圖示 (⋮)。
  3. 點擊 「加到主畫面」 或 「安裝應用程式」。

🔄 詞庫更新與自動發布作業流程 (SOP)

當您在 Google 翻譯下載了新的 CSV 詞庫檔案時，更新只需 3 步驟：

Step 1
放入新 CSV 檔案

將新匯出的 CSV 覆蓋專案目錄下的 g_translate.csv.csv。

Step 2
執行本地自動化更新腳本

系統將在 1 秒內自動完成去重、多語識別、分類歸納與網頁編譯：

python update_learning_app.py
Step 3
推送到 GitHub 自動發布

推送完成後，GitHub Pages 將在 30 秒內自動更新線上學習網頁：

git add .
git commit -m "更新詞庫與學習手冊"
git push
